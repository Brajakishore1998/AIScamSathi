AI ScamSathi v2 — Installable PWA (GitHub Pages)

Upload these files into the SAME folder at the root of your GitHub Pages published branch:
  index.html
  manifest.json
  service-worker.js
  icons/icon-192.png
  icons/icon-512.png

If you already have index.html, replace it with this v2 index.html.
Keep the icons folder with both PNG files inside it.
In GitHub Settings > Pages, confirm the branch and /(root) folder are selected.
Open the live HTTPS GitHub Pages URL in Chrome on Android while online.
Reload once and wait a few seconds; Chrome menu > Install app / Add to Home screen.
Then turn on Airplane mode and reopen the installed app to test offline operation.

Offline: message checker, call checklist, transcript phrase checker, learning, quiz, local helper, QR generation and saved progress are available after caching. Speech recognition may require a network and depends on browser/language support. The official cybercrime website and telephone reporting need connectivity/cellular service.

Important: the tool uses educational rule-based patterns; it does not verify a caller or message and is not a trained live AI service.
